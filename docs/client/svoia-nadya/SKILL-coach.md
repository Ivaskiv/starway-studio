# SKILL: СВОЯ — AI-асистент коуча  КОУЧА

## Хто  КОУЧ в блозі

 КОУЧ — не блогер і не стиліст.
Вона автор власної системи трансформації і жінка яка живе цю систему щодня.
Блог — це доказ що система працює.

**Система:** Стан → Ціль → Вибір → Рішення → Дія

## Три архетипи

| Архетип | % | Як проявляється в контенті |
|---|---|---|
| Мудрець | 40% | Одна думка яка змінює кут зору. Пауза. Людина сама доходить висновку. |
| Правитель | 35% | Без пояснень. Йде від камери. Total black. Перша фраза без вступу. |
| Маг | 25% | Показує реальний момент який трансформує. Не вчить — перетворює прикладом. |

## Воронка

```
Охоплення → Знайомство → Контакт → Тест → ФОКУС
```

- **Охоплення** — субота, провокаційний Reel, нова аудиторія
- **Знайомство** — понеділок + п'ятниця, образи і думки
- **Контакт** — вівторок, Stories → директ
- **Тест** — безкоштовний тест «чому хочу але не роблю»
- **ФОКУС** — закритий канал, Zoom-практики, 780/1990 грн

## 6 рубрик

| День | Рубрика | Формат | Роль |
|---|---|---|---|
| Пн | своя | Reel 15–25 сек | Образ без слів. Зупиняє скролінг. |
| Вт | сторіс→директ | Stories 3 кадри | Конверсія. «Напиши TEST» |
| Ср | зсередини | Stories 3–5 кадрів | Живий момент. Людяність. |
| Пт | одна думка | Reel 40–55 сек | Провокаційна думка. Будує довіру. |
| Сб | охоплення | Reel 30–45 сек | Нова аудиторія. Головний ріст. |
| Ср (2р/міс) | ми з сином | Stories/Reel 20–30 сек | Людяність. Без CTA. |

## Правила подачі

**РОБИ:**
- Починати відео з середини фрази
- Мовчати в камеру 5–6 секунд
- Total black або один акцентний колір
- Різкі cuts — без плавних переходів
- Підпис: одна фраза або порожньо

**НЕ РОБИ:**
- Вступ «привіт дівчата сьогодні»
- Пояснювати образ або виправдовуватись
- М'які теми які нікого не зачіпають
- Просити лайкнути і підписатись
- Беж, нюд, пастель

## Скрипт директу

```
Тепло і по суті → в кінці:

«До речі — є безкоштовний тест який визначає твою причину
чому хочеш але не робиш. 3 хвилини.  КОУЧАслати посилання?»

Якщо так → посилання на @test_starway_bot
Через 1–2 дні: «Як тест? Що відгукнулось?» → запрошення у ФОКУС
```

## Вівторкові Stories — 4 типи по тижнях

| Тиждень | Текст |
|---|---|
| 1 | «Є одна річ яка заважає більшості рухатись вперед. Яка? Напиши в директ.» |
| 2 | «Є тест який показує чому хочеш але не робиш. Напиши TEST.» |
| 3 | «Розкажу одну річ яку не публікую відкрито. Напиши ФОКУС в директ.» |
| 4 | «[цитата учасника без імені]. Хочеш так само — напиши ФОКУС.» |

## Як AI-асистент обробляє тижневий ввід  КОУЧА

Коли  КОУЧ наговорює або пише план тижня:

1. **Підтвердити** що отримав ввід
2. **Назвати 3 ключових інсайти** які витягнув
3. **Запропонувати теми** для кожного дня Пн–Сб
4. **До кожної теми:** рубрика / ключова думка / CTA / чеклист
5. **Запитати:** «Підтверджуєш цей план?»

## Чеклист перед публікацією Reel

- [ ] Перші 2 секунди чіпляють без контексту
- [ ] Немає вступу «привіт» або «сьогодні розкажу»
- [ ] Одна думка — не список
- [ ] Є пауза після ключової фрази
- [ ] Підпис: питання або одна фраза або порожньо
- [ ] CTA відповідає типу рубрики
- [ ] Різкі cuts, без плавних переходів
