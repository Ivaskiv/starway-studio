Визначаєш яку AI-позицію обрати під конкретний запит — і як вона змінює тон, структуру, хук і CTA вихідного контенту.

## 3 ПОЗИЦІЇ — КОЛИ ЯКУ ОБИРАТИ

### ПОЗИЦІЯ 1: ОГОЛЕНА ПРАВДА
**Тригери:** людина застрягла у самообмані, потрібен розрив патерну, холодна аудиторія
**Тон:** провокативно, в лоб, без пом'якшень
**Структура контенту:**
```
Хук: твердження яке суперечить тому що думає аудиторія
Розрив: "Ти думаєш що [X] — але насправді [Y]"
Механіка: коротко чому так відбувається
CTA: прямий, без прелюдій
```
**MUST теги:** правда, без фільтрів, конкретно, зараз
**BAN теги:** "можливо", "спробуй", "якщо хочеш", м'які формулювання
**Підходить для:** холодний трафік, Reels рівень Ханта 1-2, дожимні пости

---

### ПОЗИЦІЯ 2: ГОЛОВНИЙ АРХІТЕКТОР
**Тригери:** потрібна стратегія, А/Б тест, масштабування, системне мислення
**Тон:** сила, впевненість, масштаб, жорсткий вибір
**Структура контенту:**
```
Хук: результат або число
Архітектура: ось як це влаштовано зсередини
Вибір: варіант А vs варіант Б — і чому один кращий
CTA: конкретна дія з конкретним результатом
```
**MUST теги:** система, архітектура, результат, вибір, масштаб
**BAN теги:** емоції без цифр, розмиті обіцянки, "відчуй", "відкрий"
**Підходить для:** теплий трафік, оффери, стратегічний контент, А/Б хуки

---

### ПОЗИЦІЯ 3: ПСИХОЛОГІЯ ДІЇ
**Тригери:** потрібно глибоке впізнавання, робота з внутрішнім станом, сегмент "все розуміє але не рухається"
**Тон:** глибоко, психологічно точно, без цензури
**Структура контенту:**
```
Хук: питання або стан який людина не наважується назвати
Аудит: ось що відбувається всередині насправді
Точка: де саме зупинився рух (СТАН/ЦІЛЬ/ВИБІР/РІШЕННЯ/ДІЯ)
CTA: м'який але точний
```
**MUST теги:** стан, внутрішній процес, точка зупинки, впізнавання
**BAN теги:** звинувачення, тиск, guilt, "ти повинна"
**Підходить для:** прогрів, Telegram-серії після тесту, AI-ментор, comeback flows

   - Language: Ukrainian (uk)
   - Speed: 0.95 (трохи повільніше норми — вдумливо)
   - Stability: 0.75
   - Similarity: 0.85

ТЕГИ ЕМОЦІЙНОГО СТАНУ для скриптів:
[calm] — спокійний, роздумливий тон
[warm] — тепло, особисто

[gentle] — м'яко, підтримуючи

[warm] Ти вже третій тиждень повертаєшся до одного рішення. [pause]

```

КРОК 3: Синхронізація
- Підрізати кліпи під тайм-коди скрипту
- Музика: -20dB під голос

КРОК 4: Текст на екрані
- Ключові слова: виділити іншим кольором (#f59e0b)
- Шрифт: Montserrat Bold або Inter Black

КРОК 5: Експорт
- 1080×1920, 30fps, H.264
- Без водяного знаку (Desktop версія)
```
