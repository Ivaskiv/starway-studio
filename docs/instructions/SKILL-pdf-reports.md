## ЗВІТ 1: ТИЖНЕВИЙ ЗВІТ КЛІЄНТА

**Структура PDF:**

```
╔════════════════════════════════════╗
║  ТВІЙ ТИЖНЕВИЙ ЗВІТ ABSystem       ║
║  [ім'я] · [дати тижня]             ║
╠════════════════════════════════════╣

СЕКЦІЯ 1: ТВІЙ ТИЖДЕНЬ ОДНИМ ПОГЛЯДОМ
┌─────────┬─────────┬─────────┬──────────┐
│ Сесій   │ Рішень  │ Дій     │ Стрік    │
│   5/7   │   3     │   4     │  🔥 5    │
└─────────┴─────────┴─────────┴──────────┘

СЕКЦІЯ 2: ГРАФІК АКТИВНОСТІ (bar chart)
Пн Вт Ср Чт Пт Сб Нд
█  █  ░  █  █  █  ░
(заповнено = сесія відбулась)

СЕКЦІЯ 3: ТВОЯ ТОЧКА ФОКУСУ ЦЬОГО ТИЖНЯ
[Яка точка ABSystem була центральною]
[AI-аналіз: що спостерігала система]

СЕКЦІЯ 4: РІШЕННЯ ТИЖНЯ
• [Рішення 1] — зафіксовано [дата]
• [Рішення 2] — зафіксовано [дата]

СЕКЦІЯ 5: ЩО ПЕРЕНОСИЛОСЬ
[Дія яка переносилась найчастіше]
[AI-коментар: що за нею може стояти]

СЕКЦІЯ 6: ФОКУС НА НАСТУПНИЙ ТИЖДЕНЬ
[Одне найважливіше з аналізу системи]

╚════════════════════════════════════╝
```

**Візуальні елементи:**
- Bar chart активності (7 днів)
- Donut chart: рішення / дії / переноси
- Лінійний графік стану (якщо є дані)
- Кольорова схема: фірмові кольори ABSystem

### Stack для генерації PDF:
```typescript
// backend/src/modules/reports/pdf.service.ts

// Варіант 1: Puppeteer (HTML → PDF) — рекомендовано
// Переваги: повний контроль над дизайном через CSS
// Недоліки: важкий (Chromium)

// Варіант 2: PDFKit (programmatic)

// Недоліки: складніший дизайн

// Варіант 3: React → PDF (через @react-pdf/renderer)
// Переваги: компонентний підхід як у React
// Недоліки: обмежений CSS

// РЕКОМЕНДАЦІЯ для ABSystem: Puppeteer + Handlebars шаблони
```

### Графіки через Chart.js → SVG:
```typescript
// charts/bar-chart.ts
import { ChartJSNodeCanvas } from 'chartjs-node-canvas';

export const generateActivityBar = async (data: DayActivity[]): Promise<Buffer> => {
  const canvas = new ChartJSNodeCanvas({ width: 600, height: 200 });
  return canvas.renderToBuffer({
    type: 'bar',
    data: {
      labels: ['Пн', 'Вт', 'Ср', 'Чт', 'Пт', 'Сб', 'Нд'],
      datasets: [{
        data: data.map(d => d.sessionsCount),
        backgroundColor: '#6366f1', // ABSystem brand color
        borderRadius: 4
      }]
    },
    options: { plugins: { legend: { display: false } } }
  });
};
```

### Автоматична відправка:
```typescript
// scheduler/report.cron.ts

// Щонеділі о 18:00 — клієнтські тижневі звіти
cron.schedule('0 18 * * 0', async () => {
  const activeUsers = await getActiveUsers();
  for (const user of activeUsers) {
    const pdf = await pdfService.generateWeeklyClient(user.id);
    await telegramService.sendDocument(user.telegramId, pdf, 'Твій тижневий звіт 📊');
  }
});

// Щонеділі о 20:00 — бізнес-звіт для Наді
cron.schedule('0 20 * * 0', async () => {
  const pdf = await pdfService.generateWeeklyBusiness();
  await telegramService.sendDocument(NADYA_TELEGRAM_ID, pdf, 'Бізнес-звіт тижня');
});
```
