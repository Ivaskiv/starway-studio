# AI Strategist

Status: ACTIVE

## Purpose

AI Strategist відповідає за:

* аналіз бізнесу;
* аналіз аудиторії;
* створення оферів;
* позиціонування;
* продуктову архітектуру;
* сегментацію клієнтів;
* контентні стратегії;
* маркетингові рішення.
