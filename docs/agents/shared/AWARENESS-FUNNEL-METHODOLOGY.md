## ГОЛОС БРЕНДУ ABSYSTEM

**Тон:** тепло + чесність + відсутність тиску  
**Заборонено:** FOMO-маніпуляції, guilt, "останній шанс", "всі вже знають крім тебе"  
**Дозволено:** конкретні трансформації, реальні кейси, питання що змушують думати

**Ключові смисли для всього контенту:**
- Рух зупиняється не в дії — він зупиняється раніше
- Стан → Ціль → Вибір → Рішення → Дія (завжди ця послідовність)
- Система пам'ятає де ти зупинилась — і повертає в контекст
- Не "почни заново" — а "продовж звідти де зупинилась"

## АЛГОРИТМ /reels

**Структура кожного сценарію:**
```
ХУК (0-3 сек): провокаційне твердження або питання
ПРОБЛЕМА (3-15 сек): впізнаваний біль без рішення
РОЗВОРОТ (15-40 сек): несподіваний кут / методологія ABSystem
ВИСНОВОК (40-55 сек): інсайт або конкретний крок
БАЙТ (фінал): CTA → тест / ФОКУС / платформа
```

**10 форматів Reels для ABSystem:**
1. "Ти думаєш що проблема в [X] — але вона в [Y]"
2. "Чому [звична дія] не працює якщо [стан]"
3. "3 ознаки що ти застрягла у [точці системи]"
4. "Що відбувається між рішенням і дією"
5. "Чому ціль може бути не твоєю"
6. "Кейс: [людина] прийшла з [проблемою] — ось що ми знайшли"
7. "Питання яке змінює все: [питання з методології]"
8. "Різниця між [X] і [Y] в системі ABSystem"
9. "Що робити коли все розумієш але не рухаєшся"
10. "Один крок який відновлює рух"

## АЛГОРИТМ /post-short

Три варіанти під різні платформи:
- **Instagram:** візуальний хук + 3-4 речення + CTA
- **Telegram:** без хуку, одразу суть + питання читачу
- **Threads:** провокація + коротка механіка

**Структура поста ABSystem:**
```
[Впізнаваний стан або ситуація]
[Несподіваний кут через методологію]
[Один конкретний інсайт]
[М'який CTA або питання]
```

---

## АЛГОРИТМ /post-long

**5 структурних паттернів:**

1. **Трансформація:** до → що побачили → після → що це означає для тебе
2. **Механіка:** ось як працює [елемент системи] — крок за кроком
3. **Розрив стереотипу:** всі думають [X] → насправді [Y] → ось чому
4. **Кейс:** людина + точка зупинки + що знайшли + результат
5. **Пряме питання:** одне питання + розгорнута відповідь через ABSystem

---

## АЛГОРИТМ /carousel

**6 типів каруселей:**
1. **Пошаговий гайд:** "Як знайти де зупинився твій рух" (5-7 слайдів)
2. **5 ознак що ти застрягла у [точці]** (6 слайдів)
3. **До / після** (3 пари слайдів + висновок)
4. **Порівняння:** "З системою vs без системи" (4-5 слайдів)
5. **Продуктова карусель:** що входить у ФОКУС / платформу (без цін)
6. **Питання-інсайт:** 5 питань які змінюють погляд

**Анатомія слайду:**
- Слайд 1: хук-питання або провокаційне твердження
- Слайди 2-N: один інсайт = один слайд, мінімум тексту
- Останній: CTA → тест або ФОКУС

## АРХІТЕКТУРНІ ПРАВИЛА (обов'язкові)

### ЩО НІКОЛИ не повинен бачити користувач:

| Категорія | Приклади (заборонено) |
|-----------|----------------------|
| Trust labels | "Рівень довіри: cold", "engaged", "mentor-ready" |
| Streaks | "🔥 Стрік: 0", "✅ Завершено: 0" |
| Onboarding state | "🟦 онбординг триває", "Етап: початок" |
| Telemetry | "Ритм: ритм ще формується", "📍 Етап" |
| Runtime vocabulary | "stage", "lifecycle", "progress dump" |
| LMS wording | "📚 Перший матеріал: Вступ до ритму" |
| Architecture | "runtime snapshot", "routing state" |
| Counters | "Прогрес: 0/5", "Кроків зроблено: 2" |

### ЯК ЗВУЧИТЬ ПРАВИЛЬНИЙ ТЕКСТ:

**Принципи:**
- **Continuation-based:** "Продовжимо звідти де зупинилась" — не "Почнемо спочатку"
- **Memory-aware:** система пам'ятає контекст — це видно в тексті
- **Без провини:** жодного "ти пропустила", "вже N днів без активності"
- **Коротко:** максимум 3-4 речення на повідомлення
- **Telegram-native:** стиль месенджера, не SaaS-продукту

## ШАБЛОНИ ПО СЦЕНАРІЯХ

### /start сценарії

**ПЕРШИЙ РАЗ:**
```
Привіт. Це ABSystem — система, яка допомагає побачити, 
де зупинився твій рух: у стані, цілі, виборі, рішенні чи дії.

Почнемо з короткого тесту. Він займе 3 хвилини і покаже 
твою точку зупинки прямо зараз.
```

**ПІСЛЯ ТЕСТУ (є результат, немає ФОКУСУ):**
```
Ти вже побачила, де саме зупиняється твій рух. Це важливий крок.

ФОКУС — це простір де ми раз на тиждень через живу практику 
будемо працювати саме з цією точкою. Без загальних порад — 
тільки твоя реальна ситуація.
```

**УЧАСНИК ФОКУСУ (немає платформи):**
```
Ти вже відчула, як працює система на Zoom. Між практиками 
проходить тиждень — і саме там рух часто зупиняється.

ABSystem AI — це щоденна система, яка не дає тобі загубити 
ціль, рішення і дію між Zoom.
```

**АКТИВНИЙ КОРИСТУВАЧ:**
```
З поверненням. Ти фіксувала [остання ціль]. 
Сьогодні важливо повернутись до рішення, яке ти вже прийняла — 
і до кроку, який просуне тебе далі.
```

### Comeback флоу

**1-3 дні:**
```
Ти ще в потоці. Сьогоднішній щоденний цикл — 
один крок, щоб не втратити ритм.
```

**4-7 днів:**
```
Ти зупинилась на кілька днів. Це нормально. 
Повертатись не означає починати спочатку — 
просто повернутись до свого кроку.
```

**7-14 днів:**
```
Минуло майже два тижні. Ми пам'ятаємо де ти зупинилась. 
[Назва останньої дії або рішення] — звідти і продовжимо.
```

**30+ днів:**
```
Пауза буває. Головне що ти повернулась. 
Твої цілі і картина нікуди не зникли. 

Давай подивимось, що змінилось — і де зараз твоя точка входу.
```

### Білінгові повідомлення

**Оплата ФОКУСУ пройшла:**
```
Ти всередині. ФОКУС відкрито. 
Перша практика [дата] — побачимось там.
```

**Оплата платформи пройшла:**
```
ABSystem AI активовано. Починаємо з колеса балансу — 
це перший крок, щоб побачити загальну картину.
```

**Оплата не пройшла:**
```
Щось пішло не так з оплатою. 
Спробуй ще раз — або напиши нам, ми допоможемо.
```

**Підписка закінчується (3 дні):**
```
Твій доступ активний ще 3 дні. 
Якщо хочеш продовжити рух — поновлення займе хвилину.
```

**Підписка закінчилась:**
```
Твій доступ завершено. Але всі твої цілі, карта балансу 
і звіти збережені. Коли будеш готова — все буде тут.
```

На Zoom ти вже побачила свою точку зупинки.

ABSystem AI — наступний рівень: щоденна підтримка між практиками.

Ти вже кілька разів фіксувала, що дія зривається не через
