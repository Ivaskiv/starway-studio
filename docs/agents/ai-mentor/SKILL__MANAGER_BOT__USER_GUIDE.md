## 🎯 НАЗНАЧЕНИЕ

Цей скіл описує **як користуватися** @starway_manager_bot для управління маркетинговою воронкою за **15 хвилин на день**.

**Що робить бот**:
- ✅ Показує метрики (скільки людей купило, конверсія%)
- ✅ Генерує контент (Stories, DMs готові до публікації)
- ✅ Нагадує про завдання (что робити сьогодні)
- ✅ Дозволяє одним кліком публікувати

**Результат**: Вместо 2 години на день — 15 хвилин.

## 📊 ЩОРАНКУ: Статус воронки

### Час: 08:00

Нажми кнопку **[📊 Статус]** (або напиши `/dashboard`)

Бот покажує:

```
📊 СТАТУС ВЧОРА (09.06.2026)

• 28 /starts  (люди написали TEST в директ)
• 22 completions (люди завершили питання Q1-Q8)
• 11 payments (люди заплатили за ФОКУС)
• Conversion: 50% ↑ (好! вчора було 42%)

🎯 ТИ НА КУРСІ!
Недільна мета: 100 conversions
Маємо: 70 (70% до мети)
```

### Що означають цифри?

```
/starts = люди що написали TEST
  └─ Мета: 20+ на день (більше реклами = більше /starts)

completions = люди що завершили всі питання (Q1-Q8)
  └─ Норма: 75-80% від /starts
  └─ Якщо < 60%: питання занадто довгі або важкі

payments = люди що заплатили 15€ або 39€
  └─ Норма: 40-50% від completions
  └─ Якщо < 30%: потрібно змінити email gate або結果

Conversion = payments / completions × 100%
  └─ Твоя норма: 50%+ (дуже добре!)
  └─ Середня норма: 30-40%
```

### Якщо статус погірший:

```
Бот: "⚠️ ВНИМАНИЕ

Конверсія впала на 15% (був 50%, тепер 35%).

Можливі причини:
□ Менше теплих контактів у DMs
□ Email gate skip rate зріс (люди не вводять email)
□ WayForPay платежі не працюють
□ Dojim 2 має низькі open rates

Хочеш рекомендацію? [💡 Рекомендація]"
```
