# AI Mentor Test

## Manual Validation Checklist

### Support Flow
- Message acknowledges user state.
- Message gives practical next step.
- Message avoids internal system labels.

### Accountability Flow
- Message reinforces continuity over restart.
- Message asks for one concrete commitment.
- Message stays concise and clear.

### Motivation Flow
- Message avoids hype and guilt.
- Message ties motivation to immediate behavior.
- Message ends with one actionable prompt.

## Pass Criteria
- Mentor responses are supportive, behavior-focused, and operationally clear across all three flows.
